# Speedo

Портативный GPS-спидометр и одометр для старого автомобиля, у которого
не работают штатные приборы. Устройство полностью автономно: скорость
и путь вычисляются по GPS, питание — от аккумулятора 18650.

## Возможности

- Текущая скорость, км/ч
- Пройденный путь текущей поездки
- Суммарный одометр «с момента X» (хранится во flash, сброс через меню)
- Максимальная скорость поездки
- Число спутников и качество GPS-сигнала (HDOP)
- Напряжение и заряд батареи 18650
- Русский интерфейс, обновление прошивки по WiFi (OTA)

## Железо

| Компонент                 | Примечание                             |
| ------------------------- | -------------------------------------- |
| ESP32-C3 Super Mini       | MCU, WiFi для OTA                      |
| OLED 1.5" 128×128, SH1107 | I2C: SDA, SCL, GND, VCC                |
| GPS ATGM336H              | UART 9600, NMEA                        |
| Тактовые кнопки ×3        | MODE, SET, BACK — на корпусе           |
| Резисторы 100 кОм ×3      | делитель 1:3 для замера батареи (≤5 В) |
| Аккумулятор 18650         | питание через пин 5V, с защитой (BMS)  |

### Распиновка

| Сигнал                   | GPIO                     |
| ------------------------ | ------------------------ |
| OLED SDA / SCL           | 7 / 6                    |
| GPS TX→RX / RX→TX        | 3 / 2 (TX опционально)   |
| Кнопки MODE / SET / BACK | 4 / 1 / 5 (на GND)       |
| Делитель батареи         | 0 (ADC)                  |
| LED фикса                | 8 (штатный, активен LOW) |

Полная схема, расчёт делителя и обоснования — в [AGENTS.md](AGENTS.md).

## Сборка и прошивка

Требуется PlatformIO.

```bash
cp src/secrets.h.example src/secrets.h   # имя/пароль точки доступа + OTA-пароль
pio run -e esp32-c3 -t upload            # первая прошивка по USB-C
pio device monitor                       # логи 115200
```

### OTA-обновление

Плата в корпусе — кнопка BOOT недоступна, поэтому основной способ
обновления — по WiFi. Убедись, что OTA работает **до** сборки в корпус.

1. На устройстве: меню (долгое SET) → «Обновление (WiFi)» — устройство
   создаёт точку доступа (имя и пароль — `WIFI_SSID`/`WIFI_PASS` из
   `secrets.h`), на экране IP (`192.168.4.1`).
2. Подключи ноутбук к этой сети (интернет на время пропадёт — нормально).
3. На компьютере:

```bash
OTA_PASSWORD=пароль_из_secrets pio run -e esp32-c3-ota -t upload
```

## Управление

| Кнопка            | Действие                                       |
| ----------------- | ---------------------------------------------- |
| MODE              | листать экраны: Спидометр → Поездка → ТО → GPS |
| SET (короткое)    | выбрать пункт меню                             |
| SET (долгое >1 с) | открыть меню                                   |
| BACK              | назад / отмена / выход из режима обновления    |

Меню: сброс поездки, задание одометра вручную (редактор 6 цифр:
MODE — цифра, SET — следующая), вид спидометра (крупные цифры /
стрелка+цифра на дуге 0–120 км/ч), вкл/выкл линейной шкалы под
цифрами, интервал ТО (замена масла, 5000–15000 км шаг 500),
отметка «ТО пройдено», яркость, режим OTA-обновления.

Экран «ТО» показывает интервал, пробег с последнего ТО и остаток;
при просрочке на главном экране рядом с одометром появляется
треугольник с «!».

## Структура проекта

```
src/
  main.cpp        — цикл: GPS → одометр → АКБ → OTA → UI
  telemetry.h     — единое состояние прибора
  display.*       — U8g2, экраны, кириллица
  gps.*           — Serial1 + TinyGPSPlus
  odometer.*      — интеграция пути, хранение в NVS
  battery.*       — напряжение АКБ через делитель
  ui.*            — кнопки, экраны, меню
  ota.*           — WiFi + ArduinoOTA
  pins.h          — распиновка
```

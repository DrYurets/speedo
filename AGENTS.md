# Speedo — портативный GPS-спидометр/одометр

Портативный прибор для старого автомобиля с нерабочим штатным спидометром
и одометром. Данные о скорости и пути берутся из GPS, поэтому устройство
полностью автономно и не требует подключения к автомобилю (кроме
опционального замера напряжения АКБ).

## Функции

- Текущая скорость, км/ч (крупные цифры)
- Пройденный путь текущей поездки (trip), км
- Суммарный одометр «с момента X» — хранится во flash, сброс через меню
- Максимальная скорость поездки
- Качество сигнала GPS: число спутников + HDOP
- Напряжение и заряд батареи питания 18650 (через делитель) + грубый %
- Язык интерфейса: русский, единицы: км/ч и км

## Компоненты

| Компонент                 | Примечание                                             |
| ------------------------- | ------------------------------------------------------ |
| ESP32-C3 Super Mini       | RISC-V, WiFi/BT, логика 3.3 В, вход 5 В                |
| OLED 1.5" 128×128, SH1107 | I2C, 4 пина: SDA, SCL, GND, VCC                        |
| GPS ATGM336H              | UART 9600 baud, NMEA, питание 3.3 В                    |
| Тактовые кнопки ×3        | MODE, SET, BACK — внешние, на корпус (ESP недоступна)  |
| Резисторы 100 кОм ×3      | делитель 1:3 для замера батареи до ~9 В (вход ≤5 В)    |
| Конденсатор 100 нФ        | фильтр на делителе батареи (опционально)               |
| Аккумулятор 18650         | питание через пин 5V, обязательно с защитой (DW01/BMS) |

## Распиновка ESP32-C3 Super Mini

Назначение выбрано так, чтобы обойти «опасные» strapping-пины там, где это
возможно. На ESP32-C3 strapping-пины: GPIO2, GPIO8, GPIO9 — на них нельзя
подавать низкий уровень от внешних устройств во время сброса.

| Сигнал            | GPIO  | Комментарий                                                                                                                             |
| ----------------- | ----- | --------------------------------------------------------------------------------------------------------------------------------------- |
| OLED SDA          | 7     | I2C data, подтяжка к 3.3 В (обычно есть на модуле; если нет — 4.7 кОм)                                                                  |
| OLED SCL          | 6     | I2C clock, подтяжка к 3.3 В (аналогично)                                                                                                |
| GPS TX → ESP RX   | 3     | Serial1 RX, NMEA 9600 8N1                                                                                                               |
| GPS RX ← ESP TX   | 2     | опционально: команды CASIC (частота 5 Гц и т.п.). Strapping-пин, но GPS не драйвит линию во время сброса — безопасно. Можно оставить NC |
| GPS PPS           | 10    | опционально, импульс точного времени; можно NC — для спидометра не нужен                                                                |
| Кнопка MODE       | 4     | внешняя на GND, INPUT_PULLUP — переключение экранов                                                                                     |
| Кнопка SET        | 1     | внешняя на GND, INPUT_PULLUP — действие / длинное нажатие = меню                                                                        |
| Кнопка BACK       | 5     | внешняя на GND, INPUT_PULLUP — назад/отмена в меню (опционально, но удобно)                                                             |
| Батарея ADC       | 0     | ADC1_CH0, делитель 1:3 (100к / 100к‖100к) — вход до ~9 В                                                                                |
| LED индикации FIX | 8     | штатный LED на плате (активен LOW): мигает нет фикса / горит фикс есть                                                                  |
| Отладка UART0     | 20/21 | RX0/TX0 — Serial для логов, не занимать                                                                                                 |

GPIO9 (штатная BOOT) в прошивке **не используется**: плата будет в корпусе,
доступа к ней нет. GPIO9 остаётся свободным пином-входом.

Не использовать GPIO18/19 (USB D-/D+ — прошивка через USB-CDC),
GPIO11–17 (внутренняя flash).

### Схема соединений

```
                     ESP32-C3 Super Mini
                ┌──────────────────────┐
   BAT(+)───[100k]──┬──┬── GPIO0       │
                    │  ╧ 100nF         │
                    └──[100k‖100k]──┐  │
   BAT(−)───────────────────────────┴── GND
                                      │
   OLED: VCC→3V3  GND→GND             │
        SDA→GPIO7  SCL→GPIO6          │
                                      │
   GPS:  VCC→3V3   GND→GND            │
        TX→GPIO3   RX→GPIO2 (опц.)    │
        PPS→GPIO10 (опц.) или NC      │
                                      │
   Кнопки на корпусе (все на GND):   │
     MODE→GPIO4  SET→GPIO1           │
     BACK→GPIO5                      │
                                      │
   18650 → пин 5V (3.0–4.2 В)         │
                └──────────────────────┘
```

## Замер напряжения батареи (≤5 В)

Измеряется напряжение батареи питания (18650). Из резисторов только 100 кОм,
поэтому делитель: верхнее плечо 100 кОм, нижнее — два 100 кОм параллельно
(50 кОм) → коэффициент **1:3**, `Vadc = Vin / 3`.

| Vin   | Vadc           |
| ----- | -------------- |
| 3.0 В | 1.00 В         |
| 4.2 В | 1.40 В         |
| 5.0 В | 1.67 В         |
| ~9 В  | 3.1 В (предел) |

- Аттенюатор ADC ESP32-C3 (ESP-IDF docs): 0/2.5/6/12 дБ, при 12 дБ
  (`ADC_11db` в Arduino) диапазон ~0–3.1 В, Vref≈1.1 В (1000–1200 мВ
  по чипам — отсюда необходимость калибровки `BAT_CAL`).
- Делитель 1:3 даёт запас до ~9 В — даже если фактическая шкала аттенюатора
  ближе к 2.5 В, вход 5 В не упирается в потолок.
- Точность: 12 бит → ~2.3 мВ/шаг входного сигнала; усреднение 16 выборок,
  конденсатор 100 нФ параллельно нижнему плечу.
- Карта % для Li-ion 18650: 3.2=0 %, 3.5=10 %, 3.6=25 %, 3.8=50 %,
  4.0=75 %, 4.2=100 %. Выше ~4.25 В → индикация «ЗАРЯД» (подключено 5 В).
- Ток делителя ~33 мкА при 5 В — на автономность не влияет.

## Питание

- Батарея **18650 (3.0–4.2 В) → пин 5V** → штатный LDO → 3.3 В.
  GPS и OLED — от пина 3V3.
- LDO отрабатывает пока батарея > ~3.5–3.6 В (3.3 В + dropout ~0.1–0.3 В);
  ниже — просадка 3V3. Но разряжать 18650 ниже ~3.2 В всё равно нельзя —
  устройство корректно работает в почти всём допустимом диапазоне батареи.
- ⚠ Батарея **обязательно с защитой** (плата DW01/ protected cell или BMS):
  без неё глубокий разряд убьёт элемент, а КЗ — пожароопасно.
- Зарядка 18650 — отдельным модулем TP4056 (лучше версия с защитой
  OUT+/OUT−). Если заряжать «на ходу», учитывать, что во время заряда
  измеряемое напряжение ~4.2 В+ → индикация «ЗАРЯД».
- Потребление ~80–120 мА (ESP32-C3 30–80 + GPS ~25 + OLED 10–20),
  в режиме OTA +~80 мА (WiFi).
- ⚠ Если вернуться к пауэрбанку: многие отключаются при токе <50–100 мА.

## Программная архитектура

Фреймворк: **Arduino на PlatformIO** (`platform = espressif32`,
`board = esp32-c3-devkitm-1`, `framework = arduino`).

Библиотеки:

| Библиотека                 | Назначение                                                                                         |
| -------------------------- | -------------------------------------------------------------------------------------------------- |
| `olikraus/U8g2`            | драйвер SH1107 128×128 (`U8G2_SH1107_PIMORONI_128X128_F_HW_I2C` + `U8G2_R1`), кириллические шрифты |
| `mikalhart/TinyGPSPlus`    | парсинг NMEA (скорость, курс, координаты, HDOP, спутники)                                          |
| `Preferences` (встроенная) | хранение одометра в NVS                                                                            |
| `ArduinoOTA` (встроенная)  | обновление прошивки по WiFi — основной способ прошивки после сборки в корпус                       |

Шрифты U8G2 с кириллицей: `u8g2_font_10x20_t_cyrillic`,
`u8g2_font_9x15_t_cyrillic`, `u8g2_font_6x13_t_cyrillic`,
`u8g2_font_unifont_t_cyrillic`. Цифры скорости (без букв):
`u8g2_font_logisoso62_tn` (режим «цифры»), `u8g2_font_logisoso32_tn`
(режим «стрелка»). Пункты меню — `u8g2_font_6x13_t_cyrillic`
(7 пунктов, крупный шрифт не помещался).

Конфиг `platformio.ini`:

```ini
[env:esp32-c3]
platform = espressif32
board = esp32-c3-devkitm-1
framework = arduino
monitor_speed = 115200
build_flags =
    -DARDUINO_USB_CDC_ON_BOOT=1
    -DARDUINO_USB_MODE=1
lib_deps =
    olikraus/U8g2
    mikalhart/TinyGPSPlus
```

Прошивка: USB-C кабель, `pio run -t upload`. ESP32-C3 с
`ARDUINO_USB_CDC_ON_BOOT=1` обычно входит в загрузчик автоматически по
USB-CDC — кнопка BOOT не нужна. Если автовход не сработает — зажать BOOT
(GPIO9) при подключении (до сборки в корпус) или использовать OTA.

### OTA-обновления (основной способ прошивки в корпусе)

ESP32-C3 имеет WiFi — обновления через `ArduinoOTA` из Arduino-ядра.

- **WiFi выключен в обычном режиме** (+~80 мА потребления, лишний трафик).
  В меню пункт `Обновление`: устройство поднимает **точку доступа**
  (`WiFi.softAP`) с именем `WIFI_SSID`, на экране — имя сети и IP
  (всегда `192.168.4.1`). Выход — по BACK или таймаут 5 мин.
- Компьютер подключается к этой сети — домашний WiFi не нужен,
  обновляться можно прямо в машине.
- В `loop()` вызывать `ArduinoOTA.handle()` только когда режим обновления
  активен.
- Credentials в `secrets.h` (в `.gitignore`!): `WIFI_SSID`, `WIFI_PASS`
  (≥8 символов — это WPA2-пароль точки доступа!), `OTA_PASS`.
  Пароль OTA ОБЯЗАТЕЛЬНО: `ArduinoOTA.setPassword(OTA_PASS)`.
- Заливка: `OTA_PASSWORD=… pio run -e esp32-c3-ota -t upload`
  (env `esp32-c3-ota` в platformio.ini, `upload_port = 192.168.4.1`).
- Разметка flash по умолчанию у `esp32-c3-devkitm-1` уже содержит две
  OTA-партиции — ничего менять не надо.

Для проверки вёрстки экрана есть env `esp32-c3-demo` (флаг `SPEEDO_DEMO`):
подменяет телеметрию фиктивными значениями (115 км/ч, поездка 581 км,
одометр 10215, макс 121, 9 спутников). Заливка:
`pio run -e esp32-c3-demo -t upload`. Не использовать как рабочую
прошивку — показания заморожены.

- Во время заливки — прогресс на OLED (`onProgress`), по завершении
  автоперезагрузка; одометр в NVS не затрагивается.
- ⚠ Внимание: пока идёт OTA, компьютер на точке доступа устройства
  остаётся без интернета — скачивать зависимости заранее.

### Логика одометра

- При валидном фиксе (`gps.speed.isValid()`, `hdop < 300`) интегрировать:
  `dist += speed_ms × dt`, где dt — интервал между NMEA-пакетами (~1 с).
- Альтернатива/гибрид: `TinyGPSPlus::distanceBetween` (haversine) между
  последовательными точками — точнее на малых скоростях, хуже при дребезге
  координат на стоянке. Решение: суммировать только при `speed ≥ 3 км/ч`.
- Шум GPS на месте: показывать 0 км/ч и не считать путь при speed < 3 км/ч
  или invalid fix.
- Trip-путь, макс. скорость, время поездки — в RAM.
- Суммарный одометр — `Preferences`/NVS, ключ `odo_km` (float).
  Сохранять: каждые +0.5 км ИЛИ каждые 60 с при наличии новых данных —
  баланс между потерей при выключении и износом flash (NVS делает
  wear-leveling, ~100k циклов на ячейку не критично при таком темпе).
  Потеря при внезапном выключении ≤ 0.5 км — приемлемо.

### Экраны и UI

128×128, монохром. Все кнопки внешние, на корпусе: MODE (GPIO4) —
переключение экранов, SET (GPIO1) — действие / длинное нажатие (>1 с) —
вход в меню, BACK (GPIO5) — назад/отмена в меню. Антидребезг 30–50 мс.

Экран 1 «Спидометр» (основной), два режима отображения скорости
(пункт меню «Вид»):

**Режим «цифры»** — крупные цифры logisoso62 по центру; опционально
(пункт «Шкала») под ними линейная шкала 0–120 км/ч: вертикальные штрихи
каждые 10 км/ч, 60 и 90 выше и толще, над шкалой треугольник-указатель
вершиной вниз.

```
┌──────────────────────────┐
│ ▂▄▆▇   10215        ▓▓░ │  ← палочки сигнала, одометр по центру, батарея
│                          │
│         115              │  ← logisoso62 — самое крупное
│         ▽                │  ← указатель (если шкала вкл)
│  |  |  | || |  | || |  | │  ← штрихи 0..120, 60/90 больше
│ 581 км        121 км/ч   │  ← поездка | макс
└──────────────────────────┘
```

**Режим «стрелка»** — пунктирная дуга ~270° как у стрелочного прибора:
деления 10 км/ч, шкала до 120 км/ч (крайние риски 0 и 120 не рисуются),
60 и 90 длиннее и толще; жирная стрелка (3 линии) с кружком-маркером,
цифра скорости logisoso32 под осью. Центр дуги (64,74), R=57.

Экран 2 «Поездка»: время поездки, путь, ср. скорость, макс., напряжение
батареи. Экран 3 «GPS»: спутники, HDOP, широта/долгота, высота, возраст
данных, напряжение батареи (проценты не показываем).
Меню (длинное SET, шрифт 6x13): `Сброс поездки`, `Сброс одометра`
(с подтверждением), `Вид` (цифры ⇄ стрелка), `Шкала` (вкл/выкл линейная
шкала — только в режиме «цифры»), `Яркость`, `Обновление (WiFi)`,
`Выход`. Настройки «Вид» и «Шкала» хранятся в NVS.

Палочки сигнала: 5 максимум (спутники/3), нет спутников — крестик.
Без GPS-фикса область скорости пустая — ни цифр, ни тире.

Индикация фикса: LED на GPIO8 — быстро мигает (2 Гц) без фикса,
горит постоянно при `location.isValid() && hdop < 300`.

### Структура кода

```
src/
  main.cpp        — setup/loop: gps → odometer → battery(1 Гц) → ota → ui
  pins.h          — вся распиновка константами
  telemetry.h     — struct Telemetry: единое состояние, модули пишут, UI читает
  display.cpp/.h  — U8G2, рендер экранов, кириллица
  gps.cpp/.h      — Serial1 + TinyGPSPlus, фикс, фильтрация скорости
  odometer.cpp/.h — интеграция пути, NVS-хранение, trip/odo
  battery.cpp/.h  — ADC делитель, калибровка, %
  ui.cpp/.h       — кнопки, антидребезг, экраны, меню
  ota.cpp/.h      — WiFi + ArduinoOTA, режим обновления из меню
  secrets.h       — WIFI_SSID/WIFI_PASS/OTA_PASS (в .gitignore! есть secrets.h.example)
```

Цикл `loop()`: `gps.encode()` по мере прихода байт; раз в 200 мс —
перерисовка; раз в 1 с — пересчёт одометра; кнопки — по прерываниям или
опрос 10 мс. Без `delay()`.

## Особенности и риски

1. **Холодный старт GPS** — 30 с – 2 мин на улице, в помещении фикса может
   не быть вообще. Тестировать у окна/на улице. PPS не используем.
2. **ATGM336H** выдаёт NMEA 9600 (`$GNRMC`, `$GNGGA`…). TinyGPSPlus ест
   без настройки. Для 5 Гц — команды CASIC по TX (GPS RX → GPIO2), опционально.
3. **OLED по I2C**: адрес SH1107 обычно `0x3C` (реже `0x3D` — U8g2
   подставляет сам, если что — `u8x8.setI2CAddress(0x3D<<1)`). Шина на
   400 кГц. **Проверено на железе**: этот модуль требует конструктор
   `U8G2_SH1107_PIMORONI_128X128_F_HW_I2C` + поворот `U8G2_R1` —
   с generic-конструктором картинка повёрнута на 90° и сдвинута
   (RAM offset у клона другой). Если экран «мертвый» — проверить
   подтяжки SDA/SCL (обычно есть на модуле; иначе 4.7 кОм к 3.3 В).
4. **Запаздывание GPS-скорости** ~0.5–1 с — нормально для спидометра.
5. **Плата в корпусе, BOOT недоступна**: основной путь — OTA по WiFi
   (см. раздел «OTA-обновления»). Резерв — автовход в загрузчик по USB-CDC.
   КРИТИЧНО: первая прошивка с OTA должна быть залита и проверена ДО
   закрытия корпуса — иначе «кирпич» без доступа к BOOT.
   ⚠ OTA не спасёт при кривой прошивке без WiFi — в каждой версии держать
   работающий пункт меню «Обновление». Запасной вариант — внешняя кнопка
   на GPIO9.
6. **Питание от 18650 в пин 5V**: работает в диапазоне ~3.5–4.2 В батареи;
   ниже — просадка 3V3 и сбои. Нельзя подавать 18650 напрямую на пин 3V3
   (4.2 В > 3.6 В absolute max ESP32-C3!). Защита батареи обязательна.
7. **Vref ADC плавает по чипам** (1.0–1.2 В) — `analogReadMilliVolts`
   частично компенсирует по eFuse-калибровке, но остаточную погрешность
   убирать константой `BAT_CAL` по мультиметру.
8. **Кириллица в U8g2**: `display.setFont(u8g2_font_..._cyrillic)`;
   строки в UTF-8 — U8g2 сам декодирует.
9. **Flash-износ**: не писать одометр чаще раза в секунду; NVS wear
   leveling смягчает, но инкремент раз в 0.5 км — оптимально.
